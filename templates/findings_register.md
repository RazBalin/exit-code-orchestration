# FINDINGS

The only admission path for a problem found in passing: it is filed when found, with six keys, and
closed with its evidence. Structure checked by `python3 -B checks/continuity_check.py`.

### F-[[YYYY-MM-DD]]-[[SESSION]]-[[NN]]
state: [[OPEN / QUEUED / CLOSED / DROPPED]]
owner: [[who acts]]
session: [[the session that filed it]]
source: [[file:line, command or URL]]
statement: [[the problem, one sentence, with its size]]
closure: [[empty while OPEN; the evidence that closed it]]
